# Security Policy

Thank you for helping keep RepoDoctor secure.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.0 | Yes |
| Earlier versions | No |

Security fixes are evaluated for the latest supported version.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately.

1. Visit the repository's Security section:
   https://github.com/PedroCostinha/RepoDoctor/security/advisories
2. Select "Report a vulnerability".
3. Describe the issue, its potential impact and reproduction steps.

Do not disclose security vulnerabilities in public issues.

Never include credentials, access tokens, passwords,
private repository contents or personal information.

## Response and disclosure

Reports will be reviewed by the maintainer.

Security issues will be assessed and addressed according
to their impact and available project resources.

Please allow time for investigation and coordinated
disclosure before sharing details publicly.

## Scope

RepoDoctor is a public GitHub repository analyzer.

Its health score detects observable repository practices.
It does not certify repository security or guarantee that
an analyzed project is free from vulnerabilities.
